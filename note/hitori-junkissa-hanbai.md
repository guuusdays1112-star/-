# 販売設計：一人で純喫茶に入るための、小さな手引き

対象原稿：`note/hitori-junkissa-tebiki.md`
担当：販売（shiori-sales）
前提（リサーチより）：同ジャンルの競合は、無料の「入り方」記事と店名リスト（〜7選）が中心。「一人で入る」に絞った有料の手引きは見つからなかった。競合の価格は未確認。note の最低価格は100円。目標価格は500円。

---

## 1. タイトル案（5案）

検索されやすい言葉（一人／純喫茶／入り方）を入れ、売り込む言葉は入れない。

1. **一人で純喫茶に入るための、小さな手引き｜入り方・頼み方・居方・出方**
2. 一人で純喫茶に入る。扉の前で迷うことの、先に知っておく答え
3. 純喫茶の入り方——一人で扉を押すための小さな手引き
4. 二十分あれば足りる。一人で純喫茶に入るための手引き
5. 扉の前で引き返してしまう人の、一人純喫茶の入り方

### 採用案：1

- 「一人で」「純喫茶」「入り方」の三語がすべて入っていて、検索にかかりやすい
- 本文の大見出し・副題と同じ言葉なので、買う前と買った後で印象がずれない
- 「頼み方・居方・出方」まで並べることで、無料の入り方記事との違い（入ったあとまで書いてある）がタイトルだけで伝わる
- 「小さな」が栞の温度に合っていて、煽る感じがしない

※ note のタイトル欄に全文が入らない場合は「一人で純喫茶に入るための、小さな手引き」だけにして、「入り方・頼み方・居方・出方」は副題（本文冒頭の h3）に任せる。

## 2. 価格：500円

根拠：

- **比べる相手は無料記事**。競合の多くは無料の入り方記事なので、高い値付けは比べられた瞬間に不利になる。有料なのは中身の違い（状態×時間帯×席×一杯の組み合わせ八つ、持ち時間別の過ごし方、扉の前で読むメモ）に払ってもらう分で、500円なら「無料で足りるかも」と迷っている人が試しに買える額に収まる。
- **初めての有料 note**。Instagram からの読者は、まだ栞にお金を払ったことがない。最初の一冊は、高く売ることより、買ってもよかったと思ってもらえる経験を優先する。
- **100〜300円にしない理由**。有料部分は約5,600字で、どの店でも使える実用の内容。安すぎると「おまけ程度の中身」と受け取られ、次の有料 note の値付けも下がってしまう。
- **980円以上にしない理由**。「一人で入る」に絞った有料の比較対象がないので、相場より上という説明ができない。信頼がまだ積み上がっていない段階で、読者に大きな判断はさせない。
- **本文の言い回しと合っている**。有料ライン直前の「珈琲一杯より少し安い値段で」は、500円なら無理がない（純喫茶のブレンドは500円を超えることが多い）。値段を変えるときは、この一文も一緒に直す。

※ 競合の価格は未確認のまま。公開後に同ジャンルの有料 note が見つかったら、そのときに見直す。

## 3. 有料ラインの位置：今の位置（「見本」の直後）でよい

無料で見せる範囲：はじめに／向いている人・向いていない人／目次／見本（第5章⑦）。約1,200字。

根拠：

- **無料の部分だけで、共感と「自分向けかどうか」の判断まで済む**。「はじめに」で扉の前で引き返した経験を書き、向き・不向きで店名リストを求める人をはっきり外しているので、あとから「思っていたのと違う」と言われる購入を減らせる。
- **見本に選んだ章が合っている**。競合の無料記事にない、この手引きならではの部分は第5章（状態から選ぶ）。その形を一項目だけ見せるのが、中身の違いがいちばん伝わる。第1章（六つの理由）は無料記事と重なるので、見本に出すと「無料記事と同じ」と読まれてしまう。
- **⑦を見本にしたのが効いている**。「最初の一回にいちばん向いている」状態なので、見本を読んだ人がそのまま最初の一回を思い浮かべられる。
- **これより前に置くと**（目次の直後など）、中身の形が見えないまま払わせることになる。**後ろに置くと**（第1章の後など）、無料記事と同じ量をただで出すことになり、有料にする理由が弱くなる。

### 位置は変えず、有料ライン直前の一文だけ直す（採用済み・原稿に反映）

今の文は「有料部分には、これが八つと、扉の前で読める十行のメモが入っています。」。第1〜4章・第6〜7章が入っていることが伝わらず、中身を少なく見せてしまっている。

> 有料部分には、この組み合わせが八つと、足が止まる六つの理由への答え、入ってから出るまでの流れ、品書きの選び方、持ち時間別の過ごし方、扉の前で読める十行のメモが入っています。

- note の有料エリアの区切り線は、「珈琲一杯より少し安い値段で〜書きました。」の直後に置く（本文に書いた「ここから先は有料です（500円）」と note 画面の表示の両方が、有料部分より前に出るようにするため）。
