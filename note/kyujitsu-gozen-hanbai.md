# 販売設計：何もしない休日の午前を、純喫茶で過ごすための手引き

対象原稿：`note/kyujitsu-gozen.md`
担当：販売（shiori-sales）
症状パターン：〔1〕休み方を忘れた
実測の字数：全体8,068字／無料1,422字／有料6,646字
前提（リサーチより）：note には「何もしない休日」「予定を入れないと不安」を扱う記事が多いが、ほとんどは自宅での過ごし方か考え方を変える話で、「場所」と「午前」を決めて書いたものは見つからなかった。朝の喫茶店を生産性の時間として書く記事はあり、栞はその逆を行く。競合の価格は未確認（note.com の取得がブロックされたため）。第1作と同じく目標価格は500円。

## 1. タイトル案（5案）

検索される言葉（一人／純喫茶／休日／午前／何もしない／過ごし方）を入れる。「入り方」は第1作の言葉なので、第2作では使わない（二本が検索で同じ言葉を取り合わないようにするため）。売り込む言葉と、生産性に寄った言葉（朝活・有意義・充実）は入れない。

1. **何もしない休日の午前を、純喫茶で過ごすための手引き｜前の晩から帰り道まで、一人の九十分**
2. 一人で純喫茶に居るための手引き——何もしない休日の午前の過ごし方
3. 休日の午前、一人で純喫茶に座っていても落ち着かないときの手引き
4. 予定のない休日の午前を、純喫茶で。一人で何もしないための手引き
5. 3分で手が鞄へ、20分で腰が浮く。休日の午前を一人で純喫茶で過ごす手引き

### 採用案：1

- 「何もしない」「休日」「午前」「純喫茶」「過ごす」「一人」がすべて入っていて、「休日 過ごし方」「何もしない 休日」「純喫茶 一人」のどの検索にもかかる
- 前半が本文の大見出しとまったく同じなので、買う前と買った後で印象がずれない（第1作と同じ考え方）
- 「前の晩から帰り道まで」で、着席中だけでなく前後まで書いてあることが伝わる。「一人の九十分」で、中身の中心（第3章）が時間で示される
- 「九十分」は数字だが、効率の数字ではなく座っている長さなので、生産性の方向には寄らない
- 案2は「入る（第1作）」と「居る（第2作）」の対が綺麗だが、検索される「休日」が後ろに下がるので次点にする。マガジンを作るときのマガジン内の説明文に使える
- 案5は第1作の案4と同じ「数字で始める」型。フックとしては強いが、タイトルに置くとリールの一枚目と同じになって、クリック後の驚きがなくなる。リールとカルーセルに回す

※ note のタイトル欄に全文が入らない場合は、「何もしない休日の午前を、純喫茶で過ごすための手引き」だけにする。このとき「一人」がタイトルから落ちるので、本文冒頭の h3 に「一人」を入れる案を第8節に書いた。

## 2. 価格：500円（第1作と同じ）

根拠：

- **二本の値段を揃える**。第1作と同じ値段なら、読者は第2作を「続きを買わされる」ではなく「同じ棚にある別の一冊」として、中身だけで選べる。値段が違うと、どちらが上か・どちらが本命かという余計な比較が生まれる。
- **第2作から読む人がいる**。本文は第1作を読んでいなくても読めるように書かれていて、Instagram の〔1〕のリールから初めて栞を知る人も来る。その人にとっては、これが初めての有料 note になる。第1作と同じ理由で、最初の一冊は試しに買える額に収める。
- **有料部分が増えても上げない理由**。有料部分は6,646字で、第1作（約5,600字）より約1,000字多い。ただ、字数で値段を上げると「長いほど高い」という説明になり、栞の手引きを量で比べさせることになる。500円のまま、中身が増えた分は「買ってよかった」の側に回す。
- **下げない理由**。100〜300円にすると、第1作との差が「第2作はおまけ」「続編なので安い」と読まれる。独立した一冊として書かれている原稿の立ち位置と合わない。
- **980円以上にしない理由**。「休日の午前を喫茶店で何もせずに過ごす」を有料で扱う比較対象が見つかっていない。第1作と同じく、信頼がまだ積み上がっていない段階で大きな判断はさせない。
- **本文との整合**。本文で値段に触れているのは「ここから先は有料です（500円）。」の一か所だけ。第1作の「珈琲一杯より少し安い値段で」のような、値段に依存した言い回しはない。値段を変えるときに直すのはこの一か所。

※ 競合の価格は未確認のまま。第1作の売れ行きと合わせて、二本目の公開から一か月後に見直す。

## 3. 有料ラインの位置：今の位置（「見本」の直後）でよい

無料で見せる範囲：はじめに／向いている人・向いていない人／目次／第3章を一行にした要約／見本（第5章の型④）。1,422字（全体の約18%）。

根拠：

- **無料の部分だけで、「自分のことだ」と「自分向けかどうか」の判断まで済む**。「はじめに」の土曜の九時半の情景で〔1〕の読者は自分から名乗る。向いていない人に「朝の喫茶店で仕事や勉強をはかどらせたい人」を入れていることで、朝活の記事を探していた人をはっきり外せる。あとから「思っていたのと違う」と言われる購入を減らせる。
- **第3章の一行要約が効いている**。「3分で手が鞄へ、20分で腰が浮き、35分で罪悪感が来る。」は、揺れの順番（情景）だけを見せて、受け流し方（中身）は見せていない。読者は「自分もそうだ」と思った瞬間に、その先が有料の側にあることがわかる。無料で出しすぎにはなっていない。
- **見本に型④を選んだのが合っている**。「残らなかったのではなく、置いてきた」は一行で持ち帰れる言い換えで、しかも第6章の終わり（夕方に型④を思い出す）で回収される。見本で読んだ一行が、買ったあと本文の最後でもう一度出てくるので、「見本に出ていたところだけが良かった」とはならない。
- **これより前に置くと**（目次の直後など）、九十分の一行も見本も読めず、中身の形が見えないまま払わせることになる。**後ろに置くと**（第1章の後など）、Wilson の研究の話は「許可」として一番やわらかい部分なので無料で出してもよさそうに見えるが、第1章は第2章以降への橋渡しで、単体で読むと「落ち着かないのは普通」という一般論で終わる。無料記事と同じ量をただで出すことになり、有料にする理由が弱くなる。
- **区切り線の位置**：note の有料エリアの区切り線は、「**ここから先は有料です（500円）。**」の直後に置く。本文の案内と note 画面の表示が両方とも、有料部分の前に出るようにするため。

### 有料ライン直前の一文は、並べる順番だけ変えたい（原稿への提案。第8節の提案1）

今の文は、中身の中心である九十分が四番目に出てくる。無料部分の直前で「3分で手が鞄へ〜」を読ませているので、その続きが入っていることを先頭に置いたほうが、読者の頭の中でつながる。案は第8節に書いた。

## 7. 第1作との関係：二本をどう並べるか

### 7-1. 二本の分担

| | 第1作 | 第2作 |

| タイトル | 一人で純喫茶に入るための、小さな手引き | 何もしない休日の午前を、純喫茶で過ごすための手引き |

| 見出し画像の絵 | 扉（外） | 卓の上（中） |
| 値段 | 500円 | 500円 |

二本は「前編・後編」ではなく、**同じ棚の別の二冊**として並べる。第2作は第1作を読んでいなくても読めるので、どちらから読んでも構わないという置き方にする。読む順番を指定しない（指定すると「両方買わないとわからない」と受け取られる）。

### 7-2. 第1作から第2作への導線（第1作の原稿への提案。本文は編集していない）

第1作の中で、第2作とつながる場所が二か所ある。どちらも有料部分の中なので、第1作を買った人にだけ届く。無料部分には足さない（第1作の販売ページは、扉の前で迷っている読者のためのページのままにする）。

1. **第1作 第5章「① 休み方を忘れた」の末尾**（最も自然な接点。この項目がそのまま第2作の主題）
   > 座っていても落ち着かない午前のことは、別の手引きに分けて書きました。『何もしない休日の午前を、純喫茶で過ごすための手引き』
   （その下に note の記事リンクを埋め込む）
2. **第1作 本文末**（付録のメモの後、「最後まで読んでいただき、ありがとうございました。」の前）
   > 入ったあとの午前のことは、もう一冊の手引きに書きました。
   （その下に note の記事リンクを埋め込む）

- 「続きはこちら」「あわせて読みたい」「ぜひ」は使わない。一人称の報告の形にとどめる
- 第1作を公開後に書き足すことになるので、執筆担当の確認を取ってから入れる

### 7-3. 第2作から第1作への導線

- 第2作の「はじめに」で第1作に触れているところ（「一人で純喫茶に入る方法は、第1作に書いた。」）に、第1作の記事リンクを埋め込む。無料部分なので、第2作から来た人が「まだ一人で入ったことがない」ときに、自分で戻れる
- 「第1作」という呼び方は読者から見ると内部の呼び名なので、タイトルに置き換える（第8節の提案2）

- 第1作のリールのフックは〔7〕、第2作は〔1〕。症状の入口が違うので、同じ人に二回売り込んでいる印象になりにくい

### 7-5. まとめ売り（マガジン）：今は「無料のマガジン」で二本を並べるだけにし、有料のまとめ売りはしない

提案：
- **今**：無料のマガジン「栞の手引き」を作り、二本を入れる。値段は二本とも500円のまま、まとめ買いの値引きはしない
- **三本目が出たとき**：有料のまとめ売り（買い切りのマガジン）を検討する

理由：
- **二本では「まとめ」にならない**。二本で値引きをすると、「一本500円」の値段がすぐに崩れる。第1作をすでに買った人から見ると、あとから安いセットが出たことになり、先に買った人ほど損をする形になる
- **値引きは売り気が出る**。「セットでお得」は栞の禁則（評価語・勧誘）に近い言葉を呼び込む。告知でも「まとめて〜円」と書くことになり、一人称の報告で終える告知の形と合わない
- **第2作は単独で読める設計**。まとめ売りにすると「二本で一つ」と読まれ、第2作だけを必要としている〔1〕の読者に、要らない第1作まで買わせる判断を迫ることになる
- **無料のマガジンなら、並べる効果だけが取れる**。note の記事ページからマガジンが見えるので、どちらかを読んだ人がもう一本の存在に自分で気づける。Instagram のプロフィールのリンクも、マガジン一つにまとめられる
- **三本目で見直す理由**。三本あれば「栞の手引き」という棚として成り立ち、まとめ売りの値段（例：三本で1,200円前後）にも説明がつく。そのときも、個別の500円は残す。すでに一本買っている人が損をしない形にできるかは、note のマガジンの仕様（個別に買った記事の扱い）を確かめてから決める

### 提案4：第1作との小さな食い違い（優先度：低。両方読んだ人が気づく程度）

- **持ち物**：第1作の第5章①（休み方を忘れた）は「何も持っていかない」、第2作は「文庫を一冊。手の置き場所として」。第2作の第2章の文庫の行に、「九十分居るなら、手の置き場所が一つあったほうが楽だった」くらいの一言を足すと、方針を変えた理由として読める
- **締めの一行**：第1作は「今日もどこかの窓際で、これを書いている。」、第2作は「この手引きは、家の机で書いた。店では、何も書かなかった。」。二本並べると、店で書くのをやめた、という変化として読める。意図したものならそのままでよい。意図していなければ、どちらも直さずに済む（矛盾ではなく変化として読めるため）

- 「今すぐでなくてよいこと」（154行目）は煽りではなく、スマホを見なくてよいという文なので残す
- 「全体で約八千字」は実測8,068字と合っている
- 研究の扱いは「落ち着かないのは、珍しいことではないらしい」までにとどまっていて、リサーチの制約（効用は断定しない）を守っている。Killingsworth & Gilbert（2010）は本文で使っていないが、足さなくてよい（研究の話が増えると解説記事に寄る）
