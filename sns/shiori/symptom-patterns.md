# 症状の解像度と、行動への二段階

## 0. 前提

「忙しい人」「モヤモヤした人」は抽象すぎて企画に落ちない。ただし解像度を上げる方向を
間違えると、今度は売り手気配が出る。そこで**何の解像度を上げ、何を上げないか**を先に決める。

## 1. 三層モデル（「どこまで具体化するか」への回答）

| 層 | 内容 | 方針 |
|---|---|---|
| 第一層：状態 | 心と体が今どうなっているか | **固定の型として8つ持つ**。アカウントの骨格 |
| 第二層：状況 | 時間 × 場所 × その瞬間の動作 | **いくらでも具体化してよい**。投稿ごとの変数 |
| 第三層：属性 | 年齢・職業・性別・年収 | **書かない**。解像度を上げない |

第三層を上げるとターゲティングになり、読者は「狙われている」と感じる。
第二層を上げると情景になり、読者は「それは私だ」と自分から名乗る。
learnings.md の「場所×時間で具体的に始めるフックが強い」「状況の具体性が保存を生む」は、
第二層だけを深掘りせよという指示だと読める。

## 2. 第一層：症状パターン（八つ）

各パターンは〈状態〉と、それが外から見えるときの〈情景の種〉を持つ。
情景の種は、リール中盤で描く絵の材料になる。

1. **休み方を忘れた**
   情景の種：休日にも予定を入れてしまう。何もしない時間に落ち着かず立ち上がる。
2. **予定は埋まっているのに空っぽ**
   情景の種：今日一日の記憶が薄い。人と会った帰りの、急な無音。
3. **一人になる場所がない**
   情景の種：家にも職場にも人がいる。車の中、駅のベンチで時間を潰している。
4. **頭が仕事から離れない**
   情景の種：夜、明日の段取りが勝手に回る。寝る前にスマホを見て余計に冴える。
5. **決めるのに疲れた**
   情景の種：何を食べるかすら決めたくない。選択肢が多い店ほど疲れる。
6. **誰にも会いたくないが、一人きりも寂しい**
   情景の種：無人の部屋には帰りたくない。他人の気配だけが欲しい。
7. **時間が余ったが使い方がわからない**
   情景の種：約束まで四十分。中途半端すぎて何も始められない。
8. **自分を甘やかす口実がない**
   情景の種：休む理由を探している。誰かに許可されたがっている。

※ 7 は行動ハードルが最も低い入口。8 は締めの一行が直接効く相手。

## 3. 栞が解決していること（二段階）

- **第一段階：疑似避難**——リールを見ている数十秒だけ心が緩む。大多数はここで終わってよい。
  保存は「行動の予約」であり、第二段階の先行指標として扱う。
- **第二段階：行動**——実際に足を運び、現実のリセットが起きる。

今の締め「〇〇な時間を、あなたも。」は第一段階から第二段階への情緒的な誘いにはなっているが、
**症状にしか触れていない**。行動が起きない理由は症状ではなく障壁の側にあるので、そこが空いている。

## 4. 障壁（来たいのに来られない理由）

1. 一人で入って浮かないか
2. どのくらい居てよいのか（長居すべきか、短くてよいのか）
3. 注文の作法がわからない。常連の場所に見える
4. 話しかけられたくない／逆に無言が気まずい
5. 調べる・予約する手間
6. そもそも一時間も取れない

締めの一行には、**症状の共鳴＋障壁の解除**を両方入れる。ただし解除は情報ではなく情景で行う。

## 5. 情報 → 情景への変換

| 情報（売り手気配が出る） | 情景（栞の文体） |
|---|---|
| 一人でも入りやすい | 隣の客は文庫を伏せたまま、三十分ひとことも喋らなかった |
| 短時間でも大丈夫 | 珈琲一杯、二十分。それだけのために扉を押した |
| 静かで落ち着く | レジの奥で氷が崩れた。それが今日いちばん大きな音だった |
| 席が空いている | 昼下がり、四人掛けに一人で通された。申し訳なさは三分で消えた |
| 常連じゃなくても平気 | 注文を言い終える前に、こちらの言葉は最後まで待ってもらえた |
| メニューが少なく迷わない | 品書きは短い。私が考えることは何もなかった |

禁則：評価語（美味しい・おすすめ・映え）、命令形（行ってみて・保存して）、二人称の勧誘、店名の推奨。

## 6. 状況起点フック（テロップ一枚目の叩き台）

第二層＝時間×場所×動作で始める。症状パターンの番号を添える。

- 木曜の夜、神保町。頭がまだ会議室にいる。〔4〕
- 日曜の夕方、家に帰りたくない三十分がある。〔3〕
- 約束まで四十分あまった、銀座の裏通り。〔7〕
- 土曜の十一時、何もしていない自分が落ち着かない。〔1〕
- 人と会った帰り、まだ誰とも喋りたくない。〔2〕
- 予定は埋まっていたのに、今日の記憶が薄い。〔2〕
- 何を食べるかすら決めたくない、火曜の昼。〔5〕
- 部屋に誰もいないとわかっている夜の帰り道。〔6〕

発見リール・カルーセルの切り口としても同じ型を使う。
ノウハウ発信に寄らないため、フックの直後に解説を置かず、いきなり情景に入る。

## 7. 締めの改良案

現行の「〇〇な時間を、あなたも。」は二人称の勧誘。
**一人称の報告で終える**と、売り気が消え、同時に「そのくらいでいいのだ」という許可になる。

- 珈琲が冷めるまで。それだけの用事で構わなかった。
- 二十分の家出には、ちょうどよい椅子だった。
- 誰も私を待っていない席が、この街には案外ある。
- 一人で来ている者ばかりだったので、私も安心して一人になった。
- 何も解決しなかったが、肩の位置が少し下がった。

勧誘はしない。読者が自分で「行ってみるか」と思う余白を残す。
