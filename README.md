# ゆすらご ｜ 喫茶店ホームページ

京都の喫茶店「ゆすらご」のホームページ一式です。
**やわらかい緑 × 昭和レトロ喫茶 × ちょっとレトロPC** というデザインで組んでいます。

---

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 静的HTML版のトップページ。ダブルクリックでそのまま開けます |
| `assets/style.css` | **デザインの出典はここだけ。** 色・余白を変えるときはまずこのファイル |
| `blogger/theme.template.xml` | Bloggerテーマの雛形（CSSは流し込み前） |
| `blogger-theme.xml` | **Bloggerに読み込ませる完成形。** 下記コマンドで生成されます |
| `tools/build-blogger-theme.sh` | `style.css` + 雛形 → `blogger-theme.xml` を生成 |

CSSを直したら、Blogger版に反映するためにこれを実行してください。

```bash
bash tools/build-blogger-theme.sh
```

XMLとして壊れていないかも同時にチェックします。

## デザインの考えかた

- **色** — 基調は苔のような緑（`--moss` `#4c6b48`）と若葉（`--leaf`）。
  背景はクリーム色の紙（`--cream`）で、目に刺さらないやわらかさを優先しました。
  さし色はプリンの琥珀（`--amber`）、ナポリタンの朱（`--vermilion`）、
  クリームソーダの青緑（`--soda`）と、喫茶店のメニューから採っています。
- **レトロ** — 見出しは明朝（Shippori Mincho B1）。
  枠線は2pxの実線＋ずらした影で、昭和の看板や印刷物のような硬さを出しています。
  背景にはうっすら方眼紙の地紋。
- **ちょっとオタクっぽい** — ラベルや価格にドット絵フォント（DotGothic16）。
  お品書きと営業案内は**レトロPCのウィンドウ風**の枠（`OSHINAGAKI.TXT` / `EIGYO.SYS`）。
  ヒーローにはブラウン管の走査線と点滅カーソル、ロゴは16×16のドット絵珈琲カップ、
  フッターには90年代個人サイト風のアクセスカウンター。
  やりすぎないよう、遊びは「枠・ラベル・記号」だけに閉じ込めています。

ダークモード（OSの設定に追従）、キーボード操作のフォーカス表示、
`prefers-reduced-motion`（アニメーション無効化）、印刷用スタイルにも対応しています。

## ★ 差し替えが必要なところ

いまは**店名「ゆすらご」以外はすべて仮の内容**です。
`index.html` と `blogger/theme.template.xml` の中を `★` や `○` で検索すると該当箇所が出ます。

```bash
grep -n '★\|○○\|0000\|19XX\|20XX' index.html blogger/theme.template.xml
```

差し替えるもの一覧：

- [ ] 創業年（`SINCE 19XX`）
- [ ] 所在地の地名（`京都・○○の喫茶店`）
- [ ] 店主のことば（「店のこと」の3段落）
- [ ] 店名の由来（「ゆすらうめの古い呼び名」としていますが、違う場合は書き換えを）
- [ ] お品書き（品名・価格すべて仮）
- [ ] 営業時間・定休日
- [ ] 住所・郵便番号・電話番号・最寄り駅・席数・支払い方法
- [ ] Googleマップの埋め込みコード
- [ ] 店内写真6枚（`frame--empty` を `<img>` に置き換え）
- [ ] SNSのアカウントURL（Instagram・X）
- [ ] お知らせ2件（不要なら `<section class="notice">` ごと削除）

### 写真の入れかた

`assets/img/` に置いて、プレースホルダを差し替えます。

```html
<!-- 変更前 -->
<div class="frame frame--empty"><span>PHOTO 01</span><span class="frame__cap">カウンター席</span></div>

<!-- 変更後 -->
<div class="frame">
  <img src="assets/img/counter.jpg" alt="窓から光の入るカウンター席">
  <span class="frame__cap">カウンター席</span>
</div>
```

Bloggerで使う場合は、画像をBloggerの投稿にアップロードして
発行されたURLを `src` に指定してください。

## Bloggerへの入れかた

1. `bash tools/build-blogger-theme.sh` を実行
2. Blogger管理画面 → **テーマ** → 右上の **⋮** → **バックアップ**（※現在のテーマを必ず保存）
3. 同じメニューの **復元** から `blogger-theme.xml` をアップロード

トップページでは店舗情報のセクションが並び、その下に日記の一覧が出ます。
個別記事のページでは、ヘッダーとフッターはそのままに記事本文だけが表示されます。
日記の本文はBloggerの投稿がそのまま入るので、記事の書きかたは今までどおりです。

**元に戻したいとき**は、手順2で保存したバックアップXMLを同じ「復元」から読み込めば戻せます。

## 静的HTML版の公開

`index.html` と `assets/` をそのままサーバーに置けば動きます。
GitHub Pagesなら、リポジトリの Settings → Pages で
このブランチの `/ (root)` を指定するだけです。
ビルドも依存パッケージも必要ありません。
