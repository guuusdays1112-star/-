# 喫茶ゆすらご ｜ ホームページ

京都市上京区・仁和寺街道ぞいの京町家の喫茶店「喫茶ゆすらご」のホームページ一式です。
**やわらかい緑 × 昭和レトロ喫茶 × ちょっとレトロPC** というデザインで組んでいます。

---

## ファイル構成

編集するのは `src/` と `assets/` の3ファイルだけです。
`index.html` と `blogger-theme.xml` は**生成物なので直接編集しないでください**（上書きされます）。

| ファイル | 役割 |
| --- | --- |
| `src/sections.html` | **本文の唯一の出典。** 文章・メニュー・店舗情報はここを直す |
| `assets/style.css` | **デザインの唯一の出典。** 色・余白はここを直す |
| `src/page.template.html` | 静的HTML版の`<head>`まわり（ページ説明文・構造化データ） |
| `blogger/theme.template.xml` | Bloggerテーマの外枠 |
| `tools/build.py` | 上記から下の2つを生成する |
| `index.html` | 〈生成物〉静的HTML版 |
| `blogger-theme.xml` | 〈生成物〉Bloggerに読み込ませるテーマ |

編集したら必ずこれを実行してください。静的版とBlogger版の両方が作り直されます。

```bash
python3 tools/build.py
```

XMLとして壊れていないかも同時に検査します（Bloggerは厳密なXMLしか受け付けないため）。

### 仕組み

`src/sections.html` に書いたHTMLが両方に流し込まれます。書き分けのしるしは3つだけです。

| しるし | はたらき |
| --- | --- |
| `<!--HOMEONLY:START--> … <!--HOMEONLY:END-->` | Bloggerではトップページだけに出る（記事ページでは隠れる） |
| `<!--STATIC:START--> … <!--STATIC:END-->` | 静的HTML版にだけ出る |
| `<!--BLOGGER:START--> … <!--BLOGGER:END-->` | Bloggerテーマにだけ出る（`<b:widget>` など） |
| `{{HOME}}` | トップページのURLに置き換わる |

## デザインの考えかた

- **緑** — お店そのものが「緑の店」なので、基調は苔のような緑（`--moss` `#4c6b48`）と若葉（`--leaf`）。
  背景はクリーム色の紙にして、緑が主役になるようにしました。
  さし色はキウイソーダの青緑（`--soda`）、琥珀（`--amber`）、朱（`--vermilion`）。
- **レトロ** — 見出しは明朝（Shippori Mincho B1）。
  枠線は2pxの実線＋ずらした影で、昭和の看板や印刷物のような硬さ。
  背景にはうっすら方眼紙の地紋。
- **ちょっとオタクっぽい** — ラベルや価格にドット絵フォント（DotGothic16）。
  お品書きと営業案内は**レトロPCのウィンドウ風**の枠（`OSHINAGAKI.TXT` / `EIGYO.SYS`）。
  ヒーローにはブラウン管の走査線と点滅カーソル、ロゴは16×16のドット絵の珈琲カップ、
  フッターには90年代の個人サイト風カウンター。
  やりすぎないよう、遊びは「枠・ラベル・記号」だけに閉じ込めています。

ダークモード（OSの設定に追従）、キーボード操作のフォーカス表示、
`prefers-reduced-motion`（アニメーション無効化）、印刷用スタイル、
検索結果むけの構造化データ（JSON-LD）にも対応しています。

フッターのカウンターは、**自分のブラウザに記録した「何回目の来訪か」を出すだけの飾り**です。
実際の訪問者数ではありません。不要なら `src/sections.html` の `<p class="counter">` を削除してください。

### 写真の入れかた

`assets/img/` に置いて、`src/sections.html` のプレースホルダを差し替えます。

```html
<!-- 変更前 -->
<div class="frame frame--empty"><span>PHOTO 01</span><span class="frame__cap">吊るされた緑のラムネ瓶</span></div>

<!-- 変更後 -->
<div class="frame">
  <img src="assets/img/ramune.jpg" alt="天井から吊るされた緑のラムネ瓶">
  <span class="frame__cap">吊るされた緑のラムネ瓶</span>
</div>
```

Bloggerで使う場合は、画像をBloggerの投稿にアップロードして、
発行されたURLを `src` に指定してください（`assets/` はBloggerには置けません）。

## Bloggerへの入れかた

1. `python3 tools/build.py` を実行
2. Blogger管理画面 → **テーマ** → 右上の **⋮** → **バックアップ**
   （※いま使っているテーマを必ず先に保存してください）
3. 同じメニューの **復元** から `blogger-theme.xml` をアップロード

トップページでは店舗情報のセクションが並び、その下に日記の一覧が出ます。
個別記事のページでは、ヘッダーとフッターはそのままに記事本文だけが表示されます。
日記の本文はBloggerの投稿がそのまま入るので、記事の書きかたは今までどおりです。

**元に戻したいとき**は、手順2で保存したバックアップXMLを同じ「復元」から読み込めば戻せます。

## 静的HTML版の公開

`index.html` と `assets/` をそのままサーバーに置けば動きます。
GitHub Pagesなら、リポジトリの Settings → Pages で
このブランチの `/ (root)` を指定するだけです。ビルドサーバーも依存パッケージも要りません。

## 手元での確認

```bash
python3 tools/build.py
python3 -m http.server 8000
# → http://localhost:8000
```

フォントはGoogle Fontsから読み込むので、確認にはネット接続が必要です。
