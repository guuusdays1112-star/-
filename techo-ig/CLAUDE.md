# 手帳・文具アフィリエイト 新アカウント 実行指示書（Claude Code用）

> このファイルをプロジェクトのルートに `CLAUDE.md` として置き、Claude Codeに「CLAUDE.mdのタスクT1から順に実行して」と指示する。
> 前提：ジャンルは「文具・手帳」。本人が手帳ヘビーユーザーかは未確認のため、**実物の手元写真がなくても成立する「イラスト＋図解」型**で設計している。手元写真は撮れるものから順次差し込む。

---

## 0. このプロジェクトの目的と制約

- 目的：Instagram新アカウントで文具・手帳のアフィリエイト収益を作る。月1万円 → 1年で事業収入50万円の一部に。
- 作業時間：本人は1日30〜60分。**画像・原稿の生成はClaude Codeが担い、本人は確認・イラスト差し替え・投稿だけ**にする。
- 顔出しなし。既存の「栞（関西の喫茶店）」「楽天ROOM（ゆるミニマリスト）」と競合しないこと（喫茶店・ミニマル雑貨は扱わない）。
- Claude Codeがやってはいけないこと：Instagram・ASPへのログイン、投稿、アカウント作成、パスワード入力。**投稿ボタンは本人が押す。**

## 1. アカウント設計

### コンセプト
**「手帳が続かない人のための、手帳と文具の選び方」**
毎年買っては3月で白紙になる人に、「自分に合う1冊と1本」を15字の言葉と図解で決めてもらうアカウント。

### アカウント名案（名前欄は検索対象なので「手帳」「文具」を必ず入れる）
1. てもと手帳室｜続く手帳と文具の選び方（@temoto_techo）
2. 3月で白紙にしない手帳｜文具の選び方（@shirokunai_techo）
3. 一冊と一本｜手帳・文具の選び方（@issatsu_ippon）
4. 手帳えらびの図解室（@techo_zukai）
5. 書きたくなる手帳室｜文具レビュー（@kakitakunaru_techo）

**推し：1「てもと手帳室」**（手元だけで顔を出さない運用と一致し、覚えやすい）

### プロフィール文（150字以内）
- A：毎年3月で白紙になる人へ📒／続く手帳と、書きたくなる1本を図解で選ぶ／テレビのテロップを作るデザイナーが15字で要点だけ／保存して手帳売り場へ↓
- B：「今年こそ続けたい」を手帳選びから📒／タイプ別診断・ペン比較・続く書き方／全部イラストと図解で3分／紹介品はPRを含みます↓
- C：手帳が続かないのは、意志じゃなく相性📒／あなたに合う1冊と1本を図解で／デザイナーの手元から毎朝7時更新

### ターゲットペルソナ
- 27歳・会社員（事務職）・一人暮らし。年末に手帳売り場で30分迷い、結局去年と同じものを買う。
- 悩み：手帳が3月で止まる／どれが自分に合うかわからない／ペンも「なんとなく」で選んでいる。
- よく見る投稿：「〇〇タイプ診断」「比較早見表」「保存版まとめ」系のカルーセル。リールは流し見、保存するのは図解。

### 投稿の柱と比率
| 柱 | 比率 | 例 |
|---|---|---|
| ① 選び方チャート・診断 | 40% | 3問で決まる手帳／あなたに合う黒ペン |
| ② 比較・早見表 | 30% | 1日1ページ vs マンスリー／油性 vs ゲル |
| ③ 続ける書き方 | 20% | 3行日記／白紙ページの埋め方 |
| ④ セール・新作まとめ | 10% | ブラックフライデーで買うならこの3つ |

### デザインルール
- サイズ：1080×1350px（4:5）、1投稿8〜10枚
- 配色：背景 生成り `#F4EFE6`／文字 墨 `#2B2B2B`／アクセント 朱 `#C8553D`／補助 薄墨 `#8A8478`
- フォント：見出し `Zen Old Mincho` Bold／本文 `Zen Kaku Gothic New` Medium（Google Fonts）
- 表紙の型：上1/3に15字以内のコピー（最大96px）→中央にイラスト枠→下に小さく「保存して売り場へ」＋左上に「PR」タグ（28px、朱の枠線）
- 中ページの型：左上にページ番号「2/9」、見出し1行（15字以内）、本文は3行以内、イラスト枠
- 最終ページの型：「保存」アイコン＋「迷ったら、まずこの1冊」＋プロフィールリンク誘導
- 商品画像は**ショップや公式の画像を使わない**（著作権）。本人のイラストか自分で撮った写真のみ。

## 4. 運用ルール

### 1日の作業（30〜60分）
1. 朝7:00 投稿（5分）：Claude Codeが前日に用意した画像とキャプションを確認して投稿、ストーリーズにシェア
2. 通勤・休憩（10分）：同ジャンルの投稿に感想コメント5件
3. 夜（15〜30分）：翌日分のイラストを1点描いて差し替え、Claude Codeに翌日分の生成を指示
4. 夜（5分）：自分の投稿へのコメントに返信

夜勤の日は3を休み、週末にまとめて2〜3本分を用意する。

### 週1回（日曜夜）見る数字と判断基準（目安）
| 数字 | 見方 | 判断 |
|---|---|---|
| 保存率（保存÷リーチ） | 2%未満が続く | 表紙コピーを変える。「診断」「早見表」型に寄せる |
| プロフィールアクセス率 | 低い | 最終ページの誘導文とプロフィール文を見直す |
| リンククリック数 | アクセスはあるのに低い | リンク先ページの商品数を3つに絞る |
| もしもの発生件数・報酬 | 0件が4週続く | 紹介商品の価格帯を上げる（万年筆・カバー） |
| フォロワー増加 | 伸びた投稿 | その型を翌週2本に増やす |

## 6. Claude Codeへのタスク（この順に実行）

### T1 プロジェクト作成
```
techo-ig/
  CLAUDE.md          # このファイル
  posts/2026-10-13/  # 投稿ごとのフォルダ
    slides.json      # 各ページの文言
    caption.txt
    out/             # 書き出したPNG
  templates/         # HTML/CSSテンプレート
  illust/            # 本人のイラスト（なければプレースホルダー）
  scripts/render.py
```

### T2 テンプレート作成
- 「1. デザインルール」に従い、表紙・中ページ・最終ページの3種をHTML/CSSで作る。
- フォントはGoogle Fontsから取得。取れない場合はNoto Serif JP / Noto Sans JPで代替し、その旨を報告。
- イラスト枠は `illust/<投稿日>/<ページ番号>.png` を読み、なければ点線枠に「ILLUST」と表示。

### T3 書き出しスクリプト
- `scripts/render.py <投稿日>` で slides.json を読み、Playwrightで1080×1350のPNGを `out/01.png`〜 に書き出す。
- 表紙に「PR」タグが入っていなければエラーにする。
- 見出しが15字を超えたら警告を出す。

### T4 原稿の流し込みと商品確認
- 「3. 完成原稿」の3本を slides.json と caption.txt に変換。
- 残り11本は「2. カレンダー」と柱の型に沿って原稿を作り、**同じ形式で本人の確認待ち**にする。
- 紹介商品は投稿前日にWeb検索で現行品・おおよその価格を確認し、`posts/<日付>/products.md` に記録。廃番・品切れは差し替え案を出す。

### T5 チェック
- 全PNGを目視確認（文字のはみ出し、PRタグ、ページ番号）。
- キャプション冒頭の「#PR」と末尾の広告表記があるか確認。

### T6 競合調査
- Instagramで「手帳 選び方」「文房具 比較」系のカルーセルを主に投稿する顔出しなしアカウントを3〜5件探す。
- 表にまとめる：アカウント名／フォロワー規模／真似すべき点／避けるべき点。
- 実在が確認できないものは載せない。

### 完了の定義
- `posts/2026-10-13/out/` に9枚のPNGと caption.txt がそろい、本人がスマホに送ればそのまま投稿できる状態。
